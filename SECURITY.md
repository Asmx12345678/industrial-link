# Security Policy

IndustrialLink is a portfolio and internal-network prototype. The current release does not provide
API authentication, RBAC, TLS/mTLS, device certificates, rate limiting, or production hardening.
Do not expose its HTTP, TCP, UDP, or MQTT ports directly to the public Internet.

Please report suspected vulnerabilities privately through the repository owner's GitHub profile.
Do not include credentials, personal data, or exploit details in a public issue.
